# 生活（dsh-balance）

右栏的「生活」页签下分两个子模块，共用同一个选中日期和月份：

- **收支**：月历上每天显示支出/收入小计，点一天记一笔、改一笔或删一笔；下面是本月逐日、12 个月收支柱状图和支出分类占比，顶部是当月收入 / 支出 / 结余。
- **饮食**：月历上每天显示摄入 kcal，点一天看/改当天的每餐食物；下面是本月逐日摄入和 12 个月日均摄入图。

两个子模块互不串数据：收支模式不显示饮食卡片和摄入图，饮食模式不显示账目和收支图。

## 在哪打开

两个常驻入口，打开的是同一个面板：

1. **会话标题栏右侧的日历按钮**（悬停提示「打开生活面板」，可随时再打开）；
2. **右栏空状态（guide）里的「生活」卡片**——右栏还没开过任何页签时能看到，点一下就在右栏打开生活页签。

打开后，右栏页签条上会出现「生活」chip，之后就是切页签；关掉它以后再用上面任意一个入口打开。面板可以拖宽，也能展开成全屏：窄的时候竖着排，宽到 720px 以上收支模式变成左右两栏（左边日历和图表，右边当天账目和表单），饮食模式变成四宫格——左上日历、右上本月逐日、左下月度摄入、右下当天饮食（当天饮食高度会变，放在最下面，不顶动上面两格）。

## 看谁（用户切换器）

切到「饮食」子模块后，月份导航下面会出现一个「看谁」下拉框：

- **主电脑（连容器）**：列出 `diet.db` 里有资料或有记录的所有人（昵称 + QQ），默认选配置里的 `dietQq`；
- **家人电脑（快照模式）**：列出 `diet.json` 里导出的人（导出范围由 `mirror.json` 的 `data.dietUsers` 决定）；
- 切换后，当天的饮食卡片、本月逐日摄入、月度日均三块一起换成那个人的数据；
- 「记一餐」记到当前选中的人；改克数/删食物/删餐按条目 id 走，不受切换影响；
- 只读镜像下切换照常可用，只是写操作仍然被拒绝。

配置项：`dietQq`（默认看谁），不配就用 `99132013`。

## 怎么记（收支模块）

- 月历：点某一天，下面「记一笔」表单的日期就是那天；左右箭头换月，跨年也行；「今天」一键回到本月。
- 「本月逐日」清单里点一行，等同于在月历上点那一天（选中并滚到当天账目）。
- 键盘：Tab 到月历后，用 ←/→ 走一天、↑/↓ 走一周、Home/End 跳到月初/月末；整张月历只占一个 Tab 停靠点。
- 类型：支出 / 收入（两个按钮，`aria-pressed` 跟随）。
- 金额、分类、备注：分类和备注都会从历史里找相似的几条做下拉推荐（↑/↓ 选择、回车确认、Esc 关闭）；分类还带默认分类，备注输入为空时给最近用过的。
- 「记下」保存；列表里每条右边有「编辑 / 删除」，删除要先点一次「确认删除」（再点「取消」可以退回）。
- 编辑中的账目会在表单上方标出来（「正在编辑 11月3日 的支出：¥25.5」）——它可能和你当前看的日子不是同一天。
- 右栏滚到看不见表单时，点某一天会自动把「当天账目」卡片带到眼前。

## 图表（收支模块）

- **本月逐日**：这个月每一天一根柱——收入向上（绿）、支出向下（红），柱子按当月最大值等比缩放；下面列出有账目的日子（日、星期、支出、收入、笔数），点任意一行就跳到那一天，方便「这个月哪天花得最多」。没账目的日子柱子是空的，清单里也不列。
- **月度收支**：一年 12 个月，每月两根柱（收入 / 支出），鼠标悬停看具体金额，当前月那一列有底色；标题下面是全年合计和峰值。
- **支出分类**：本月支出按分类横向排（最多 8 条，其余并成「其他」），带金额和占比。
- 顶部三块：当月收入 / 支出 / 结余（结余为负时标红）。
- 颜色只用在图形（柱、分类条、图例圆点）上；金额文字走主题前景色，深浅色主题下都看得清。

### 支出分类详情

「支出分类」右上角的「按备注看详情」会展开本月支出的备注分组：

- 按金额从大到小取前 20 组；短备注会吸收包含它的长备注（例如「外卖华莱士」「外卖香河肉饼」都归到「外卖」），没有备注的归到「未备注」；
- 点一组展开看每笔（日期、备注、金额）；
- 顶部输入关键词（比如「外卖」）可以筛选所有备注包含它的支出，清空后恢复分组列表。

底部那行是状态：读账本时显示「正在读账本……」；记完/删完显示「已记下 …」「已删除 …」；平时显示数据文件路径。读失败时顶部会出现一条红字和「重试」按钮，不会静默失败。

## 饮食模块的图表

切到「饮食」子模块后，两张图都是摄入口径：

- **本月逐日摄入**：选中月每天一根 kcal 柱，超过每日目标标红；下面列出有记录的日子，点一行跳到那天；
- **月度摄入（日均）**：一年 12 根柱，每月取「有记录日子的日均 kcal」，超过目标标红；
- 月历格子也显示每天的 kcal（没记录的日子为空）。

数据走 `/balance/diet-month`、`/balance/diet-year`，和「当天饮食」同一份 diet.db。

## 当天饮食（饮食子模块）

切到「饮食」子模块、选定某一天后，会看到「当天饮食」卡片：

- 按餐列出早餐/午餐/晚餐/夜宵/加餐，每样食物显示克数、热量和 P/F/C；
- 「改克数」改单项，按食物成分表重算这一项和整餐；
- 「删」删一项，「删餐」删整餐（要确认）；
- 「加食物」往这一餐里加一项（名字要能在 1677 条成分表里匹配到）；
- 「记一餐」在这天新建一餐；
- 「重算」先按成分表逐项重算；还有库外成品菜时，会把整餐交给 DSH 拆食材再算（十几秒到半分钟），用结果替换整餐；
- 面板每 30 秒静默同步一次，汐汐在 QQ 里改了当天饮食，这里会跟着变。

数据源是汐汐的 `diet.db`（AstrBot 容器内 `/AstrBot/data/plugin_data/astrbot_plugin_diet_log/`）。
宿主**只读不直接写**——所有写操作走容器里的 `scripts/panel_api.py`（`docker exec` 调 Python），
因为宿主跨 Docker 挂载直接写 WAL 库会把容器的 `-wal/-shm` 弄坏（2026-11-24 踩过一次，容器重启才恢复）。
需要 Docker Desktop 和 `astrbot` 容器在跑；容器不在时这张卡片会报「调不动 docker」。

## 数据

默认目录 `C:\custom\workzone\balance`（在 `cordis.patch.yml` 的 `config.root` 改）：

```
balance\
  ledger.json   ← 全部账目
  README.md     ← 格式说明（插件首次写入时生成；已存在就不再动）
```

`ledger.json` 长这样：

```json
{
  "version": 1,
  "updatedAt": "2026-11-20T10:00:00.000Z",
  "entries": [
    {
      "id": "bm3k9f2a1x",
      "date": "2026-11-20",
      "kind": "expense",
      "amount": 25.5,
      "category": "餐饮",
      "note": "午饭",
      "createdAt": "2026-11-20T02:00:00.000Z",
      "updatedAt": "2026-11-20T02:00:00.000Z"
    }
  ]
}
```

- `date` 是本地日历日 `YYYY-MM-DD`；`kind` 是 `expense`（支出）或 `income`（收入）；`amount` 是元，最多两位小数。
- 写入是「临时文件 + 改名」的原子替换，写到一半不会留下坏文件；读改写排在同一把队列里，并行记账不会互相覆盖。
- 文件坏了（少了逗号、日期写成 `2026-02-30`）会明确报错并指出是第几条，**不会**清空或覆盖你的文件。
- 手工编辑、复制备份都行；插件不缓存账本，打开面板 / 点刷新就读到最新文件。

## 给 Agent 的工具

| 工具 | 用途 |
|---|---|
| `balance_add` | 记一笔（日期默认今天，类型默认支出） |
| `balance_list` | 按日期区间 / 类型查账，返回明细和区间合计 |
| `balance_edit` | 改或删一条（先用 `balance_list` 拿到 id） |
| `balance_summary` | 某月合计 + 分类 + 最近 6 个月趋势 |

所以可以直接在对话里说「今天午饭 25」「这周花了多少」「把刚才那笔改成 30」。面板和工具走同一个账本对象、同一套校验：面板里能做的 Agent 也能做，反之亦然。

## 安装与自测

- 安装（本地 link）：`dsh plugin --profile web add link:C:\custom\workzone\playground\dsh-balance`
- 或者在 Web 的 **Plugins** 页面用「Add plugin」选这个目录；装完刷新页面。
- 自测：
  - `node test/ledger.test.mjs` —— 账本读写、校验、并发、损坏文件、汇总、RPC 错误形状；
  - `node test/client.test.mjs` —— 注册面、无浏览器渲染（react-dom/server）、日历与聚合纯函数。

## 已知限制

- 账本是单文件全量读写：几万笔以内没感觉，再大就该换存储了。
- 面板挂在右栏页签上，按会话打开/关闭；它读的是同一份账本，换会话看到的数据一样，只是要重新打开。
- 同一时刻只有当前窗口这一份视图：两个窗口各开一份时，要各自「刷新」才看得到对方刚记的账。
- 面板接口 `/balance/*` 需要浏览器的登录 cookie；未登录时面板会提示「请刷新页面重新登录」。
- 分类是自由文本，没有分类管理、预算、多账本、帐户（卡/现金）概念。
- 金额只支持人民币「元」，没有多币种和汇率。
- 图表是 CSS 柱状图和分类横条，没有折线图、饼图、导出图片或 CSV。
- 按天汇总以「日期」为准，没有时区换算：账目日期就是你在表单里看到的那一天。
- 日历格子里金额超过三位数会只显示整数（全精度在当天面板、格子悬停提示和读屏文字里）；看 1 月时，补位的去年 12 月日子不显示小计（点一下会切到那一年并显示）。
